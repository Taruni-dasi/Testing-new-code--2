# Настройка офлайн-аудио и установка PWA

## 1. Кнопка «Установить»
На странице есть кнопка «📲 Установить». Она появляется автоматически, когда Chrome
готов предложить установку (событие `beforeinstallprompt`). В адресной строке также
появляется иконка «Установить приложение» — это поведение Chrome: подсказка показывается
не на первой же секунде, а после того, как SW активен и сайт открыт повторно/некоторое время.

Если кнопки нет: chrome://flags/#enable-unlimited-storage не нужен; вместо этого
DevTools → Application → Manifest → «Trigger beforeinstallprompt event» для проверки.

## 2. Офлайн-аудио: один клик на дорожку
mp3-файлы тяжёлые (10–24 МБ), поэтому они НЕ кэшируются при установке сайта
(иначе install падал бы при любом обрыве сети и PWA вообще не активировался).
Чтобы дорожка работала офлайн:
1. Откройте сайт онлайн.
2. Выберите нужную мантру в списке и нажмите «▶ Играть» хотя бы один раз
   (достаточно начать воспроизведение — файл попадёт в кэш Service Worker).
3. После этого дорожка доступна офлайн навсегда, пока вы не очистите данные сайта.

Все образы, index.html, манифест и иконки кэшируются сразу и работают офлайн без условий.

## 3. Если после деплоя ничего не изменилось
Старый Service Worker может жить в браузере до 24 часов. Принудительно:
DevTools (F12) → Application → Service Workers → галка «Unregister» +
Application → Storage → «Clear site data», затем перезагрузите страницу (Ctrl+Shift+R).
